# NODIVA — Encuesta de satisfacción estudiantil

Formulario público: https://alediaz07.github.io/nodiva-encuesta-satisfaccion/

## Instituciones disponibles

El formulario solicita seleccionar obligatoriamente una de estas dos instituciones:

- CTP Carlos Luis Fallas (CALUFA) — Alajuela
- CINDEA Montes de Oca — San Pedro

Las respuestas se envían al Google Apps Script configurado en `index.html` y se registran en la hoja de cálculo de NODIVA.

## Publicación

El sitio está alojado en GitHub Pages. Este cambio genera una ejecución nueva del flujo de publicación, independiente de los artefactos duplicados de una ejecución anterior.
